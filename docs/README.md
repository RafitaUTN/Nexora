# DocuMind Desktop — Documentación

Aplicación de escritorio inteligente para PYMES: organiza, analiza, indexa y permite búsquedas inteligentes sobre miles de documentos (PDF, Word, Excel, imágenes) mediante IA, con funcionamiento completo sin conexión.
